# On-screen keyboard and other input

Package A9, after C3. Size L.

**There is.** Screen reader support, zoom, contrast, sticky, slow and bounce keys. No on-screen
keyboard, mouse keys, dwell click, switch input or colour filters was found.

**Work.** An on-screen keyboard as an input method (also for touch); mouse keys and dwell; switch
input by scanning; Bande's own keyboard answers the approval prompt; colour filters. People who use
a screen reader, this keyboard and a switch try the prompt.

**Done when** everything in the prompt, sign-in and lock can be done without a hardware keyboard and
by no other program.

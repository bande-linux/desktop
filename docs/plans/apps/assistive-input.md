# On-screen keyboard and other input

Packages A12a, after C3, and A12b. Size L. C4 waits for A12b.

**There is.** Screen reader support, zoom, contrast, sticky, slow and bounce keys. No on-screen
keyboard, mouse keys, dwell click, switch input or colour filters was found.

**Work.** An on-screen keyboard as an input method (also for touch); mouse keys and dwell; switch
input by scanning; registering an assistive device through polkit, as consent for typing is, so that
it may answer the approval prompt; colour filters. People who use them try the prompt before C4
begins.

**Done when** everything in the prompt, sign-in and lock can be done without a hardware keyboard by
someone who registered their device, and by no program that did not.

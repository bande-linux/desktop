# Mouse keys, dwell and colour filters

Package A9, after C3. Size M.

**There is.** Screen reader support, zoom, contrast, sticky, slow and bounce keys. No mouse keys,
dwell click or colour filters was found.

**Work.** Mouse keys, dwell click and colour filters in the compositor, with their settings. People
who use a screen reader or the keyboard only try the prompt.

**Done when** everything in the prompt, sign-in and lock can be done with the keyboard alone, and
with the pointer moved by keys.

# PDF editing in Viewer

Domain: [documents](../../architecture/intents/domains/documents.md). Package A7, after D1c. Size
L.

**There is.** Reading and drawing in a confined process, page text and outline, creating PDFs. What
creates cannot change an existing file. `lopdf` is packaged.

**Work.** In the confined process, as an incremental update: order, rotate, remove and insert pages;
merge and split; fill forms; notes, highlight, ink, with the screenshot tool's markup; text copied
from pictures too; text recognised from scans when a recogniser is installed. Signatures are shown,
and a change that breaks one says so first.

**Done when** files from five producers survive every edit in three other readers, and a hostile
file reaches nothing.

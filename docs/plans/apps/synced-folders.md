# Synced folders

Domain: [files](../../architecture/intents/domains/files.md). Package A11, after D1a. Size L.

**There is.** Servers mounted by Files; no synchronisation.

**Work.** A folder here and one on a WebDAV or SFTP server the person has, kept the same: when
asked, at set times, or while on chosen networks; conflicts kept as both; deletions to Trash on both
sides; what is synced shows in Files, and counts as written where others can read.

**Done when** a week of edits on two computers and a pulled plug lose nothing.
